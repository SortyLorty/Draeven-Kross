# Draeven Kross · scheda

Scheda interattiva di Draeven Kross (D&D 5e, Paladino della Conquista liv. 6) come web app installabile.

- `index.html` – la scheda (tutto in un file, ritratti compresi)
- `manifest.webmanifest`, `icons/` – nome e icona (il volto di Draeven) sulla schermata Home
- `sw.js` – copia offline: dopo la prima apertura online funziona anche senza rete, font compresi

I dati (PF, slot, risorse, zaino) si salvano nel browser del dispositivo.

## Aggiornare
Sostituisci i file e cambia `VERSION` in `sw.js` (es. `draeven-v4`), così il tablet scarica la nuova versione.
